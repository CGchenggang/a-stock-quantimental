# a-stock-quantimental

## 当前架构

本项目面向 A 股量化研究，采用 **数据 → PIT → 因子 → 市场状态 → 概率模型 → Walk-forward/OOS → Recommendation Ledger → AI Research Agent** 的分层结构。

### 数据边界

- 历史行情进入本地数据层，保留来源、事件时间、可用时间、版本和原始引用。
- 回测/研究只允许使用 `available_time <= decision_time` 的数据。
- A 股、海外市场、宏观、政策/事件采用统一数据契约。
- 政策与地缘事件作为可追溯事件输入，不做主观政治评分。
- AI Agent 负责研究编排、证据整理和解释，不得修改 Quant 层的因子、概率或数据质量。

### 数据路线

P13 正在建设本地历史数据与多市场数据基础设施，优先覆盖：

1. A 股日线与指数/行业历史数据；
2. 海外指数、汇率、利率和主要商品；
3. 国内宏观数据；
4. 政策、监管和公告事件；
5. PIT 校验后再进入因子、Regime、Probability 和 OOS。

> 当前项目不接入券商自动交易 API。实盘前必须完成真实历史数据验证、OOS 验证和人工复核。
