# P13-M：行业相对强弱（AKShare/巨潮，无 Tushare Token 路线）

## 目标

在 P13-I～P13-L 连续未发现稳定增量后，测试“个股相对于其历史上当时所属行业的表现”是否包含超出通用市场/个股技术因子的增量信息。

本阶段严格区分：

- **行业归属生效时间**：由巨潮行业变更记录的“变更日期”构造；
- **数据可用时间**：项目为 PIT 安全设置的保守时间；
- **真实发布时间**：当前接口没有提供，不作假设。

## 数据源

AKShare 当前提供 `stock_industry_change_cninfo`，对应巨潮资讯 `p_stock2110`，返回股票行业归属变动记录，包括：

- 证券代码
- 变更日期
- 分类标准编码
- 行业编码
- 行业门类 / 行业次类 / 行业大类 / 行业中类

项目只使用**申银万国行业分类标准（008003）**。

申万 2021 版将一级行业调整为 31 个，因此本阶段先固定一级行业，避免二、三级行业过细造成小样本和高方差。

## PIT 约定

从历史变更记录构造区间：

- `effective_from = 变更日期 00:00 +08:00`
- `effective_to = 下一次变更日期 00:00 +08:00`
- `available_time = 变更日期次日 16:00 +08:00`

最后一条记录的 `effective_to` 为空，表示截至导入数据末端仍有效。

这里的 `available_time` 是**项目保守安全约定**，不是巨潮实际发布时间。由于当前接口没有给出每条历史行业变更的发布时间，因此宁可延迟一天进入回测，也不把“变更日期”直接当成可获得时间。

一级行业代码采用项目内部规范：

`SW1:<一级行业名称>`

这样不把历史记录中的更细粒度“行业编码”误当成一级行业代码。

## 当前实现

- `src/astock_v2/industry.py`：行业归属 PIT 数据契约、可用性选择、重叠区间检查。
- `tests/test_industry.py`：已有 PIT/区间测试。
- `scripts/import_cninfo_industry_membership.py`：AKShare/巨潮历史行业变更 → PIT 一级行业区间。
- `tests/test_import_cninfo_industry_membership.py`：变更记录去重、冲突检测、区间构造测试。
- `scripts/import_tushare_industry_membership.py`：仍保留作为备选数据源，但 P13-M 默认不再要求 Tushare Token。

## 第一阶段：单股可行性验证

先只验证 `300308`，不要一次跑 8 只。

在项目根目录：

```powershell
python scripts/import_cninfo_industry_membership.py `
  --symbol 300308 `
  --start 20200101 `
  --end 20260927 `
  --output data/industry/cninfo_sw1_membership.csv `
  --raw-output data/industry/cninfo_industry_change_raw.csv
```

成功后应看到：

```
300308: N SW industry-change rows
raw rows: N -> data/industry/cninfo_industry_change_raw.csv
membership rows: N -> data/industry/cninfo_sw1_membership.csv
```

这里 N 不预先假定，因为巨潮历史行业变更数量取决于实际数据。

## 单股验收标准

第一步先检查：

1. 能返回 `008003` 申万记录；
2. `行业门类` 非空；
3. 同一股票同一变更日期没有冲突的一级行业；
4. 区间按变更日期连续排列；
5. `available_time` 不早于 `effective_from`；
6. 本地 CSV 不提交 GitHub。

只有这一步通过，才扩展 8 只股票。

## 第三阶段：行业相对收益 OOS

只有 8 只股票的行业归属和 PIT 验证全部通过，才进入因子实验：

- baseline
- baseline + `industry_relative_return_5`
- baseline + `industry_relative_return_20`

协议保持：

- train=252
- test=20
- step=20
- gap=1
- train-rate baseline
- Brier / Log Loss 主指标
- Accuracy 辅助指标

行业收益必须只使用当时属于该行业的本地历史成员和价格数据；不能使用今天的行业成分回填历史。
