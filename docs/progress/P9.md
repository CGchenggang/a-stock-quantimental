# P9 Progress Report

## P9-A~D Initial Factor Engine

Added an executable P2 factor layer on top of the existing PIT contracts.

Implemented factors:
- momentum: close-to-close return over a configurable lookback;
- volatility: annualized population standard deviation of log returns;
- trend: latest close relative to the lookback simple moving average;
- volume_ratio: latest volume relative to the preceding lookback average.

All calculations consume explicit provider observations and pass through the shared factor input gate. Future or fallback inputs cannot become admissible factor values. Insufficient history returns value=None rather than fabricating observations.

## P9-E Factor Registry

Added FACTOR_REGISTRY and compute_factor() as the named dispatch boundary for downstream probability/risk stages. Each result retains PIT quality, provenance, method, lookback, and observation count.
