## Safety Rules

- Do not delete V1 scripts yet.
- Do not call cached or fallback observations "real-time" without provenance.
- Do not feed legacy single-index regime labels into the validated V2 model as if they were multi-input regimes.
- Do not use legacy proxy fund-flow labels as confirmed capital-flow facts.
- Do not migrate a legacy output until a V2 regression test exists.

## P8-C Regression Scope

Regression tests compare contract semantics rather than implementation details. Current coverage includes provenance/fallback, event_time versus available_time, daily and minute OHLCV preservation, missing timestamp rejection, and persisted cache timestamp preservation.

A V1/V2 mismatch is allowed only when the V2 contract intentionally changes behavior; such a change must be explicit and tested.

## P8-D Regression Scope

The V2 orchestration adapter accepts legacy collector outputs without executing legacy scripts inside the V2 layer. A legacy snapshot is not realtime-admissible unless an explicit availability timestamp is supplied, and even then the adapter keeps it marked as compatibility input until field-level PIT semantics are migrated.

## P8-D CLI Integration

Added a V2 `legacy-snapshot` CLI command that normalizes existing V1 morning/pre-market JSON through the orchestration boundary. It does not execute V1 collectors and does not infer realtime status from `generated_at`.

## P8-E Cache / Artifact Audit

- Audited `scripts/data_layer.py`: legacy cache envelopes persist a `ts`, but `_cache_get()` intentionally returns only `data`, so the V2 migration must read the envelope through the dedicated legacy-cache adapter when availability/provenance matters.
- Existing legacy TTLs remain behaviorally unchanged: realtime market cache 5 minutes, daily history 1 hour, intraday cache 4 hours in trading hours / 24 hours outside trading hours, macro/FX caches 1 hour, and trade calendar cache 1 day.
- The V2 `legacy_cache` adapter preserves `saved_at_unix` and computes cache age before PIT conversion; an expired cache is rejected rather than admitted as fresh.
- Removed tracked Python bytecode artifacts under `scripts/__pycache__`; generated bytecode must not be part of the repository.
- Corrected postmortem model feedback construction is already type-safe (`dict(model_feedback or {})`).

## P8-F Provider Adapter Scope

Added focused adapters for the highest-value legacy market payloads: realtime quote, daily history, and intraday K-line results. Each adapter requires an explicit V2 `available_time`; intraday data additionally requires an explicit `scale` and `klines` list so an unknown-granularity payload cannot enter the V2 intraday contract.

These adapters preserve the original payload rather than recomputing values, and preserve fallback/provenance metadata through `ProviderResult`. They are compatibility adapters, not claims that the underlying V1 source is PIT-complete.
