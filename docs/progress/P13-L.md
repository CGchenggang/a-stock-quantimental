# P13-L：相对收益 / 市场中性信息实验

## 目标

P13-K 已完成指数市场状态变量实验。本阶段切换到不同的信息定义：不再只问“市场处于什么状态”，而测试“个股相对于参考市场走得怎么样”。

第一轮只测试简单、可解释的相对收益：

- relative_return_5 = stock_return_5 - index_return_5
- relative_return_20 = stock_return_20 - index_return_20

参考指数固定为 sh000300、sz399006、sh000001。暂不加入 Beta、回归残差或个股专属阈值。

## PIT / 样本约束

- 股票和指数均来自本地 HistoricalRecord。
- 决策边界固定为事件日 16:00:00+08:00。
- 当前股票记录与当前指数记录必须同时满足 available_time <= decision_time。
- 当前日期指数不可用时，不允许用旧指数记录冒充当前日期。
- 5/20 日 lookback 使用股票与指数共同存在的交易日期，不使用自然日减法。
- revision 按 decision_time 选择最高可用版本。
- 不读取 realtime cache。
- 用户本地历史行情不提交到 GitHub。

## OOS 协议

保持 P13-I/P13-K 一致：

- train = 252
- test = 20
- step = 20
- gap = 1 个交易样本
- 每个训练窗口独立计算 train-rate probability baseline
- Brier / Log Loss 为主要概率质量指标，Accuracy 为辅助指标
- pooled 结果仅汇总各股票独立模型的 OOS 预测，不代表 pooled-trained model

## 实验变体

1. baseline：momentum + volatility + trend + volume_ratio
2. sh000300：baseline + 相对沪深300 5/20 日收益
3. sz399006：baseline + 相对创业板指 5/20 日收益
4. sh000001：baseline + 相对上证指数 5/20 日收益
5. all_indices：baseline + 三类相对收益全部加入

股票池固定为上一阶段的 8 只：

000001, 000333, 000651, 002594, 300308, 600036, 600519, 601318

## 验收标准

本阶段是诊断实验，不预先指定有效结论。只有在多个股票、多个 OOS 时间段上出现可重复的概率质量增量，并且相对于 train-rate baseline 的 Brier / Log Loss 方向稳定，才进入下一阶段。

单只股票的 Accuracy 改善、单一时间段改善或 pooled Accuracy 改善，都不足以单独选择因子。

## 下一步

- 若相对收益没有稳定增量：停止继续扩充相似技术因子，转向行业/板块相对强弱或基本面等不同信息源。
- 若相对收益出现稳定增量：先做预先固定的时间分段/block bootstrap 稳定性验证，再考虑 Beta/残差等更复杂市场中性表示。
