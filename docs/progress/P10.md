# P10 Progress Report

## P10-A Baseline Probability Model

Added a dependency-free logistic probability model. Training consumes rows of FactorOutput and routes every row through the existing probability input gate, so future, fallback, missing-value, or otherwise inadmissible factors block training.

The model stores factor names, coefficients, intercept, training-row count, learning rate, and epoch count. Prediction also reuses the probability input gate and returns a calibrated-by-model score only in the mathematical sense of a logistic probability output; calibration against observed frequencies is still a separate P10 stage.
