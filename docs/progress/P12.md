# P12 — Recommendation Ledger 与 AI Research Agent

## 已完成
- RecommendationRecord：固定记录决策时间、动作、概率/置信度、模型版本、数据质量、理由和 provenance。
- LedgerReview：独立记录事后结果，不修改原始决策字段。
- 明确动作集合：BUY / HOLD / SELL / NO_ACTION。

## 约束
- Ledger 只记录量化/研究层已经产生的结果，不允许 LLM 改写概率、因子值或数据质量。
- 概率字段表示模型输出；除非经过校准和 OOS 验证，不解释为真实胜率。
- provenance 必须能够回溯到数据或模型版本。
- 事后 review 与原始 recommendation 分离，避免 hindsight 污染原始记录。
