# P11 Progress Report

## P11-A Walk-forward Windowing

Added a dependency-free, time-ordered walk-forward window generator. It creates explicit train/test slices with no random shuffling and exposes index boundaries for auditability.

This is only the validation skeleton. It does not claim strategy performance and does not yet implement A-share transaction costs, T+1 constraints, suspensions, limit-up/down execution, benchmark attribution, or full OOS metric aggregation.
